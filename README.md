# MUWE OpenAPI Documentation

Developer documentation for the MUWE Mexico OpenAPI platform.

This repository contains:

- English and Spanish integration documentation.
- A static documentation site based on VitePress.
- A machine-readable OpenAPI contract under `openapi/openapi.yaml`.

## Local Development

```bash
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
```

The generated static site is written to `docs/.vitepress/dist`.
