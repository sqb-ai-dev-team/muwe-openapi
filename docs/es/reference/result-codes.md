# Codigos de resultado y error

| Codigo | Significado |
| --- | --- |
| `INVALID_PARAMS` | Parametros invalidos. |
| `INVALID_TERMINAL` | Terminal invalida. |
| `ILLEGAL_SIGN` | Firma invalida. |
| `PAY_SUCCESS` | Pago exitoso. |
| `PAY_FAIL` | Pago fallido y cancelado. |
| `PAY_IN_PROGRESS` | Pago en proceso; consultar. |
| `PRECREATE_SUCCESS` | Orden QR creada. |
| `REFUND_SUCCESS` | Reembolso exitoso. |
| `CANCEL_SUCCESS` | Cancelacion exitosa. |

Guarde codigos desconocidos sin descartarlos; pueden venir del proveedor.
