# Proveedores de pago

`payway` identifica el proveedor y `sub_payway` el metodo.

| `sub_payway` | Metodo |
| --- | --- |
| `1` | Barcode Payment |
| `2` | QR Code Payment |
| `3` | WAP Payment |
| `4` | Mini Payment |
| `5` | APP Payment |
| `6` | H5 Payment |

La disponibilidad de `payway` se habilita por partner durante onboarding. No codifique disponibilidad fija en el cliente.
